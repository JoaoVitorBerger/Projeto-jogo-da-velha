# 🎮 Jogo da Velha

Projeto desenvolvido para praticar os fundamentos do desenvolvimento web, utilizando HTML, CSS e JavaScript para criar um jogo da velha interativo executado diretamente no navegador.

A aplicação reproduz a dinâmica clássica do jogo, permitindo que os jogadores realizem jogadas em um tabuleiro e acompanhem o resultado da partida.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do tabuleiro e dos elementos da interface.
- **CSS3:** estilização do jogo e apresentação visual dos elementos.
- **JavaScript:** implementação da lógica das jogadas e interação com o tabuleiro.

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/JoaoVitorBerger/projeto-jogo-da-velha.git
```

### 2. Acesse a pasta do projeto

```bash
cd projeto-jogo-da-velha
```

### 3. Execute o jogo

Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server no Visual Studio Code.

Não é necessário instalar dependências ou configurar um servidor back-end para executar a aplicação.

Aplicar conhecimentos de HTML, CSS e JavaScript na construção de uma aplicação interativa, exercitando a manipulação de elementos da página, a lógica de programação e o desenvolvimento de interfaces web.
